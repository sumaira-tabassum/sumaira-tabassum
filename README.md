- Built **100+ automations** for businesses in the US, UK and Australia
- Full-stack developer with **React, Next.js, React Native and Node**, with **6 apps** shipped live. When a no-code tool hits a limit, I write the missing piece myself
- Based in **Lahore, Pakistan**, open to full-time roles (remote or in Lahore) and freelance projects
